# fixloop-core

The domain of Fixloop: task specs and model output schemas (`spec.py`, `outputs.py`, `models.py`),
the loop (`loop/`), verification (`verify_python.py`, `verify_sql.py`), context assembly
(`context.py`, `repomap.py`), patching and policy, traces, the model layer (`llm/`), and the
adapters for Postgres, Redis and object storage. See the repository README and
`docs/architecture.md`.
